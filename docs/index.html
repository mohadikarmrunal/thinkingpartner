How to use it

About ten minutes the first time. After that, one double-click before your call.

First time: install and set up

Install

Open Terminal and paste:

git clone https://github.com/mohadikarmrunal/thinkingpartner.git
cd thinkingpartner
./scripts/setup.sh

Start it

In the same Terminal, run ./run.command. Allow Screen Recording and Microphone when macOS asks, then start it again. Setup opens in your browser.

Pick your AI

Tick Qwen (free), Claude, ChatGPT, or all three. For Qwen it recommends the right size for your Mac and downloads it in one click. For Claude/ChatGPT, paste your key and set a spending limit.

Pair your second device

Add your documents if you like, then scan the QR code with your iPad or phone camera. Tap Share → Add to Home Screen.

Every call

Start

Double-click run.command in the thinkingpartner folder, or run ./run.command in Terminal.

Open

Tap ThinkingPartner on your second device's home screen. It reconnects automatically.

Pick a mode

Interview, Meeting, Learning or Brainstorm.

Talk

Join your call as usual and share your screen if you need to. Glance at your second device; tap Pin to keep an answer.

Requirements: a Mac with macOS 14 or later (15+ to hear your own microphone), Apple Silicon recommended. Your second device just needs a web browser and the same Wi‑Fi.

Use it responsibly

ThinkingPartner transcribes what other people say. Get consent where the law requires it, and respect the rules of interviews, exams, and meetings that don't allow AI assistance.
